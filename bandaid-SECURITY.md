# Security Policy

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public issue. Instead, contact [Nirmal](https://github.com/Nirmal2OO8) privately through GitHub with a concise description, reproduction steps, and the affected version.

## What counts as a vulnerability

- Local file system access beyond the intended music library paths
- Discogs API key exposure or token leakage
- Electron context isolation bypasses or remote code execution risks

## What doesn't need a private report

- UI bugs, broken styling, or missing features — open a regular issue
- Discogs API outages or rate limit behaviour

## Keep this in mind

Never include your Discogs API key or OAuth token in issues, screenshots, or logs when reporting.

## Supported versions

Security fixes are applied to the latest released version only.
